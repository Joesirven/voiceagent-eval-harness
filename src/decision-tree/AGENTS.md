# AGENTS.md: `src/decision-tree/`

The voice agent's decision tree as data, with its loader, validator, and compiler to a Pipecat Flows configuration. It also holds the tree JSON files and generated flow files.

Parent: [`../AGENTS.md`](../AGENTS.md). Root rules: [`AGENTS.md`](../../AGENTS.md).

## Contents

- `five-steps.flow.yaml`: Five-step flow configuration file for the voice agent, with JSON-shaped content.
- `flow-compiler.ts`: Compiles the decision tree into a flow configuration intermediate form and a YAML flow file.
- `full-tree.flow.yaml`: Generated flow configuration for the fictional Northwind Insurance Agency renewal tree.
- `full-tree.json`: Short fictional renewal decision tree for Northwind Insurance Agency.
- `index.ts`: Re-exports the validator, loader, and types of the decision tree.
- `loader.ts`: Loads and caches the decision tree, and projects it into the engine and live view shapes.
- `tree.json`: Copy of the short fictional renewal tree used for tests and simple runs.
- `types.ts`: Types for the decision tree: areas, flow steps, action types, nodes, answers, and gates.
- `validate.ts`: Checks a decision tree and returns every problem found, including confidence bars and banned abbreviations.

## Rules

- full-tree.flow.yaml is generated by pnpm tree:flow from the full tree. Do not edit it by hand.
- Every answer needs its own minimum confidence. Destructive actions and endings are judge-gated.
- Spoken lines are guidance for the language model, not fixed text. The compliance disclosure is the one fixed line.
- Follow the root `AGENTS.md`.
- If you add, rename or remove a file here, update this list.

## Language Rule: No Acronyms
Never use unexplained acronyms in anything written here or in any agent-facing instruction: spell out "knowledge base", "decision record", "work in progress", and so on. Universally-lexicalized technical names (URL, JSON, SSH, API, iOS) and literal identifiers that must match files or code (for example the decision files named `DEC-2026-00N-*`) are allowed, glossed in plain words on first mention. Carry this rule verbatim into every AGENTS.md, CLAUDE.md, skill, or prompt you write or update.
